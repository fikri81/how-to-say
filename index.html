🏁 PIT 2: RUMUS KALIMAT - 4 POLA SAKTI

Pola 1: Untuk menyebutkan masalah (The Problem)

The problem is + [kerusakan] + on/in + [komponen]
The problem is an oil leak in the engine.
The problem is a misfire on cylinder number 2.

Pola 2: Untuk menjelaskan gejala (The Symptom)

The engine + [gejala] + when/because...
The engine is overheating because the radiator is clogged.
The engine makes a knocking sound when you accelerate.

Pola 3: Untuk menjelaskan penyebab (The Cause)

It seems that / This is caused by + [penyebab]
It seems that the spark plug is dirty.
This is caused by a clogged fuel filter.

Pola 4: Untuk menawarkan solusi (The Solution)

We need to + / I recommend + -ing + [tindakan]
We need to replace the spark plug.
I recommend cleaning the radiator and changing the coolant.
It will cost around... and take about 2 hours.

🏁 PIT 3: CONTOH DIALOG LENGKAP

CUSTOMERGood morning. My car has a problem. The engine is hard to start in the morning.

MECHANICGood morning, Sir. I understand. Does the engine make any strange noise?

CUSTOMERYes, there is a clicking sound.

MECHANICOkay. Let me check. It seems that the battery is weak and the spark plug is dirty. This is caused by lack of maintenance.

CUSTOMERWhat should we do?

MECHANICWe need to replace the battery and clean the spark plugs. It will take about one hour and cost around 500 thousand rupiah. Is that okay?

CUSTOMEROkay, please do it.

🏁 PIT 4: LATIHAN - UBAH KELUHAN JADI PRO

1. Keluhan: "Mobilnya brebet pas langsam"
➡️ Jawaban Pro: Sir, the engine misfires / has a rough idle. It looks like there is a problem with the fuel injector.
2. Keluhan: "Mesin panas terus, air radiator habis mulu"
➡️ Jawaban Pro: The problem is engine overheating. This is caused by a leak in the radiator. We need to fix the leak.
3. Keluhan: "Tenaga ngempos di tanjakan Ketapang"
➡️ Jawaban Pro: There is a loss of power when climbing. It seems that the air filter is clogged. I recommend replacing it.
